Privacy Policy

Effective date: February 13, 2026

This Privacy Policy explains how Job Tracking and Analysis ("the Service") collects, uses, and protects information when you use this website and related API endpoints.

1. Information We Collect

  • Job listing details submitted through the API or website tools.
  • Operational metadata such as timestamps and request diagnostics.
  • Authentication headers used only to validate authorized write access.

2. How We Use Information

  • To display and manage job tracking entries.
  • To support features such as applied-status tracking and data updates.
  • To secure the API against unauthorized updates.

3. Data Storage

Data may be stored on third-party infrastructure providers (for example, Vercel and Neon) based on deployment configuration. We retain data only as needed to provide the Service.

4. Data Sharing

We do not sell personal data. Data is shared only with service providers required to run the Service (hosting, database, and observability tools) or when legally required.

5. Security

We use reasonable technical safeguards, including API key-based write protection, but no method of transmission or storage is guaranteed to be 100% secure.

6. Your Choices

You may request deletion of stored job data by contacting us or using supported in-app controls when available.

7. Changes to This Policy

We may update this policy from time to time. Changes will be posted on this page with an updated effective date.
